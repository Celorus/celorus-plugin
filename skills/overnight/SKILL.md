# The overnight

The overnight runs on the Celorus desk server, never on this computer. Once a day, before the
working day opens, the desk server runs it over each seat's graph whose firm's plan includes
it, in the firm's storage, and writes every page itself. This skill says what it does and
where it runs. It runs nothing and writes nothing.

## House rules

1. Numbers and rows come only from a tool. The model writes sentences and never counts.
2. A page is shown from the path the tool returns, never retyped.
3. A refusal names its valid values. A tool that cannot run says so in one sentence, and the skill stops.
4. Nothing is sent. A mail stops at a draft.
5. Every change ends in the desk's own history.
6. The seat must be known before anything is written.

These hold over every section of this skill. Where a section below seems to ask for something
they forbid, they win.

## Say where it runs

Read `celorus/desk.md` on this machine.

- On a seat's graph (`celorus/desk.md` says `layout_version: 3`), say that the overnight runs
  on the desk server once a day, before the working day opens, where the firm's plan includes
  it, and that it cannot be run from this computer: "run the overnight" is answered with that,
  and nothing is run. Then say what it does, in words: the day's conversations grow the
  shared pages, the latest hand-overs move each family's owner, the records made from the desk
  get their ids onto the family's person page, new mail on a family's thread becomes a reply
  row, and the day's board is written for `day-open`, every change with its line in the
  desk's own history.
- On any other desk, say that the overnight runs only over a seat's graph, on the desk
  server, and that this desk is not one, so nothing runs on its own here.

Say it runs "once a day, before the working day opens", never at a clock time.

A routine made in the app for the overnight before now cannot run it any more: the desk tools
on this machine no longer carry it. `remove-desk` names each routine still on this machine, to
be taken out.

## Signing in

This skill is free and runs on this machine without signing in, and it never calls the
record. It reads only the desk on this machine; the overnight itself runs on the desk server.

## Never

- Never write a page, a row or a history line yourself, and never do the overnight's work by
  hand from these instructions.
- Never make, change or delete a routine: a person does, in the app.
- Never say the overnight runs at a clock time.
- Never send a mail or a message.
