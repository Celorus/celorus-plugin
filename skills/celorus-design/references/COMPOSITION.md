# Composition Contract — the anatomy gate

Tokens have had hard gates from day one (contrast build, hex policy). Composition — the
thing that actually makes an artifact read as Celorus — had none, and the 2026-07-08 audit
showed the consequence: a token-perfect artifact that missed the anatomy read as a pale
cousin, while an off-token page that nailed the anatomy read as the brand. This contract
makes the anatomy checkable. `tools/composition-lint.mjs` is the executable form; this file
is the reasoning and the rules the lint cannot check.

## Declare the surface

Every HTML artifact declares what it is, in `<head>`:

```html
<meta name="celorus-surface" content="collateral">
```

| class | means | start from |
|---|---|---|
| `collateral` | standalone data/report page (report, cap table, FH, synthesis, form) | `templates/html/report.html` etc. |
| `command` | command view — ops command, control center, owner brief | `templates/html/ops-command.html` |
| `tier1-artifact` | full-page hosted artifact (claude.ai artifact viewer) | same anatomy as collateral/command + embedded fonts |
| `tier2-embedded` | plugin panel, iframe, chat widget, ≤480px card | `guides/PLUGIN_SURFACES.md` |
| `app` | app-shell UI (sidebar/topbar product surface) | `templates/html/dashboard.html` |
| `deck` | slide deck | `templates/html/deck.html` |
| `marketing` | website page, one-pager | `marketing/` |
| `banner` | fixed-size export surface | `marketing/banners/` |
| `email` | the one sanctioned inline-hex surface | `marketing/email/` |

An undeclared surface is a lint ERROR. The declaration is the contract handle: it tells
the lint — and the next maker — which anatomy this page owes.

## What the lint enforces (per class)

Errors fail CI; warnings print and pass. See the matrix in `tools/composition-lint.mjs`
(it is the source of truth for levels).

- **Theme bridge** — `prefers-color-scheme` detection + `data-theme` stamp, print always
  light. All classes except banner/email.
- **Provenance** — "Generated by Celorus · date · sources cited inline". Everything except
  banner/email; the live marketing site is a documented warn-level exemption (AGENTS rule 4).
- **Deep-teal topbar** — required on collateral / command / tier1-artifact; **forbidden
  (warn) on tier2-embedded** — the host owns the window there.
- **Eyebrow → h2 rhythm** — warn-level heuristic; deep-teal close bands are exempt (they
  open with a plain serif h2 by design).
- **Hex literals** — scanned in CSS scope only (`<style>` + `style=""`), data-URIs
  excluded, so prose issue-refs can't false-positive. The inlined GENERATED foundation
  paste-block is sanctioned (SKILL steps 2/5 mandate inlining it where CSP blocks
  `<link>`; its hexes are the tokens, gated where they are built): the scan skips from
  the block's header sentinel to the end of that `<style>` block, and skips explicit
  `/* lint:allow-token-block */ … /* lint:end-token-block */` fences — closed pairs
  only, an unclosed fence sanctions nothing. Everything else stays strict
  (`tools/composition-lint.test.mjs` pins both directions).
- **Type floor** — literal `font-size` below 9px is an error, 9–10px a warning. The token
  floor is 10px (`fontSize-3xs`); micro-type creep is how dashboards rot.
- **Embedded fonts** — tier1-artifact must carry `data:font/woff2` (CSP-sandboxed hosts
  block font CDNs; inline `tokens/dist/embedded-fonts.css`).
- **Wordmark vs theme** — a file that can flip (declares the theme bridge) and ships
  `celorus-mono-white.svg` must also ship a light-surface counterpart
  (`celorus-primary.svg` / `celorus-mono-black.svg`) and swap them on `[data-theme]`.
  The topbar rides `bg.inverse`, which is deep teal in light and **cream in dark**; the
  wordmark is a fixed-colour asset, so a lone white mark falls to **1.05:1** there.
  Banners/email are exempt (no bridge, they cannot flip). Added 2026-08-10 after all
  eight templates shipped this while passing every other check.

## The inverse surface — the trap this system actually fell into

`--semantic-color-bg-inverse` is deep teal in light and **cream in dark**. That flip is
deliberate: "inverse" means the opposite of the page. But **only tokens flip with it.**
Two things do not, and both shipped broken:

1. **Raw primitives.** `--primitive-color-petrol-300` reads on deep teal (6.70:1) and dies
   on cream (2.48:1); `--primitive-color-dark-ink-*` is worse (1.19:1). Anything on the
   inverse surface takes `--semantic-color-fg-on-inverse{,-muted,-faint}` or
   `--semantic-color-accent-on-inverse`. A **component** token bound to a primitive has
   the same defect and cannot be fixed downstream — `component.nav.topbar-accent` was
   bound to `{primitive.color.petrol.300}` and so was frozen in dark by construction.
2. **Fixed-colour assets.** The wordmark SVGs — see the lint rule above.

The mirror-image mistake is treating an *always-deep-teal* surface as if it flipped. The
`.kfi-grid.on-dark` weight strip is deliberately fixed; it takes primitives, and mixing
`bg.inverse` into it turned its tiles cream inside a deep-teal frame. **A surface that
flips takes semantics; a surface that is fixed takes primitives. Never mix them on one
component.**

`tokens/build.mjs` now also refuses any contrast pair declared in one theme only — the
original hole was a `PAIRS` table with 34 light rows against 17 dark ones, with the two
topbar rows in the missing half, reporting "51 pairs passed" the whole time.

## What the lint cannot check — still binding

1. **Curate, don't index.** A command view keeps ≤10 items in the priorities rail above
   the fold; everything else collapses into its domain panel. An exhaustive index is a
   different artifact from a briefing — if you need both, the briefing layer goes on top.
2. **Verdict headlines.** The hero states a verdict ("What's running, and what needs you"),
   not a topic ("Status dashboard"). At most one phrase recolored petrol via `<em>`.
3. **Stat values render serif at display scale** (26px+), never mono-small. Mono is for
   identifiers and data cells, not for the number the reader came for.
4. **Word + color, never color alone** — status pills carry the word, dots pair with text.
5. **Blind spots are declared** — a "?" value ships with an enable action, never as an
   unexplained gap.

Rules 6 to 13 were taken from outside design skills on 2026-10-04 (D43 records what was
taken and what was refused). They bind the same way.

6. **Button labels stay on one line** at desktop width. Shorten the label before you
   shrink the type.
7. **One label per intent.** Two controls on one page that do the same thing carry the
   same words.
8. **Re-read every visible string before it ships**: headings, labels, buttons, captions,
   alt text, error messages. Rewrite anything ungrammatical, anything whose referent is
   unclear, and anything that reads clever instead of plain (`brand/VOICE.md`).
9. **Every animation has a reason**: hierarchy, sequence, feedback or a change of state.
   No reason, no animation. Duration comes from the motion tokens
   (`--semantic-motion-duration-fast` 80ms, `-quick` 120ms, `-base` 200ms, `-slow` 320ms)
   and easing from `--semantic-motion-easing-{standard,out,in}`. The reduced-motion rule
   in the foundation block stays in force.
10. **Design every state of an interactive element**: rest, hover, focus, disabled,
    loading, error and empty. A state left to the browser default is a gap, not a design.
11. **The browser's own parts take tokens**: text selection, the text caret, scrollbars,
    the focus ring, link underline offset, and tabular numerals
    (`font-variant-numeric: tabular-nums`) in every column of numbers. The foundation
    block ships all six (D46): selection in solid petrol with on-accent text, the caret in
    petrol, the scrollbar thumb in `fg.faint` on a clear track, links offset by
    `--component-link-underline-offset`, and tabular numerals on every `table`. Three gaps
    stay with the maker: selectable text on a solid petrol fill (a solid chip, a primary
    button) swaps the pair in its own `::selection` (`fg.on-accent` ground, `accent.default`
    text), since petrol on petrol does not show; a column of numbers outside a `table`
    (a KFI grid, a stacked list) sets `tabular-nums` itself; and an app built on
    `tokens.css` rather than the foundation block sets all six from the same tokens. A
    browser without `scrollbar-color` support keeps its own scrollbar; leave it.
12. **Self-checking is bounded.** One inspection round that covers both themes and both
    widths (desktop, and narrow below the 820px `md` breakpoint), one batch of fixes, at
    most one confirming round. This binds a maker's own checking. Lane review is
    unchanged.
13. **Spacing rhythm.** More space above a heading than below it: a section opens on the
    60px section space (`--semantic-space-section`) and its h2 keeps 8px beneath. Body
    text runs 65 to 75 characters a line; cap prose blocks with a `max-width` in `ch`.
14. **The pale sea carries the structural blocks (D50).** KFI tiles, quote blocks, verdict
    bands and card-name headers sit on `block.muted` (`sea.tint-soft`, the pale sea) with
    `block.muted-fg` or the body inks. `bg.paper` is for content cards, tiles and callouts,
    which lift off the canvas by hairline (`border.default`, the sky hairline) and shadow,
    not by value. Orange UI never sits on `block.muted`: `accent2.default` measures 2.95:1
    there, so the Quarter mark goes on paper or on the canvas, never on a muted block. In dark
    mode, small petrol or orange text never sits on a muted block inside a card (the composite
    measures about 4.1 and 4.3:1, under AA; founder's ruling, 17 Oct): headings there take
    `block.muted-fg`, and large values, chips, icons and lines in the two inks pass and stay.
15. **Identity rules (D49).** The mark is the Quarter (`brand/logos/celorus-mark.svg`) and
    the wordmark is the drawn asset: never re-type the wordmark in a font, never redraw
    either, never change their proportions; only the fill changes with context, and the
    orange appears once per element, never recoloured. Minimums: mark 16 px (the one-ink
    marks 24 px), wordmark 90 px wide, horizontal lockup 28 px high, Milan 32 px; under the
    wordmark's minimum the Quarter stands alone. Milan, the mark with her face, belongs to
    product and desk surfaces only: never the storybook scenes, decks or collateral.
16. **Identity motion on the web is hover only, never idle.** Mark: the face fades in over
    240 ms and blinks once at 380 ms (`scaleY` 1 to 0.1 to 1, 70 ms each way), then fades
    out on leave. Wordmark: the eye appears in the o over 220 ms and blinks once at 360 ms
    (140 ms). Under `prefers-reduced-motion` the face and eye appear and nothing blinks. In
    product Milan may blink idly every 4 to 8 s.

## Running it

```bash
node tools/composition-lint.mjs templates/html/*.html marketing/landing.html \
  marketing/one-pager.html marketing/banners/*.html marketing/email/email.html
```

CI runs exactly this (`.github/workflows/ci.yml`) plus the token/contrast gate on every
push and PR. For a new artifact outside the repo, run the lint on the file before
delivering; the celorus-design skill bundles a copy (`assets/composition-lint.mjs`).
